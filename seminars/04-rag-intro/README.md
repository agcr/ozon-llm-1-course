# Семинар по теме "Введение в RAG"

Состоит из нескольких тюториалов:

- llm.ipynb                     -- учимся подавать запросы к LLM с помощью библиотеки _openai_
- _rag_langchain.ipynb_         -- создаем RAG-систему с помощью библиотеки _langchain_
- _sbert.ipynb_                 -- ранжируем с использованием библиотеки _sentence_transformers_
- _faiss.ipynb_                 -- знакомимся с векторными индексами на примере _faiss_

Чтобы запустить ноутбуки у себя, надо создать виртуальное окружение:
```
python3 -m venv .venv/seminar-04-rag-intro
source .venv/seminar-04-rag-intro/bin/activate
pip install -r requirements.txt
```
